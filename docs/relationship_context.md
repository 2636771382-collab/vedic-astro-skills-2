# 关系分析长期上下文

本目录保存关系/吠陀占星/合盘任务的长期上下文，用于之后每个新任务读取，不依赖旧聊天记录。

每次执行关系/吠陀占星/合盘任务前，必须先读取：

- docs/relationship_context.md
- docs/person_a_user.md
- docs/user_vedic_chart.md
- docs/person_b_hanqi.md
- docs/hanqi_vedic_chart.md
- docs/relationship_timeline.md
- docs/how_to_analyze.md
- docs/open_questions.md

回答时必须区分：

1. 现实事实
2. 盘面推断
3. 主观假设
4. 未来概率

禁止编造韩琪的真实想法。禁止把占星当作绝对事实。占星只作为结构化解释模型。重要判断必须说明依据来自现实事件、D1、D9、D10、Vimshottari Dasha、Shadbala、Ashtakavarga、Yogas、Arudha、Jaimini Karakas或合盘关系。回答必须用中文，结构清晰，避免泛泛鸡汤。
回答风格补充：在不编造他人真实想法、不把占星当绝对事实的前提下，优先给出最符合现实路径的主判断、具体时间窗口、好处坏处和趋利避害策略；避免反复使用“高/中/低概率”“不是完全……”等模糊话术。需要表达不确定性时，应说明边界和依据，而不是用含糊措辞回避判断。
